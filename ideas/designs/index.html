Concept A

Stage Amber & Marquee Bold

Backstage theater aesthetic with warm amber/gold accents, deep carbon dark mode, big tactile pill buttons, and quick-tap status badges.

  • Vibe: Theatrical, warm, industrial yet refined.
  • Colors: Amber/Gold (#f59e0b), Crimson (#ef4444), Carbon (#0f172a).
  • Key Features: Large chunky stat counters, actor avatar badges, single-tap status pills, high visibility in dim backstage lighting.

Concept B

Electric Cobalt & Neo-Brutalist

Punchy modern tool aesthetic with ultra-thick borders, electric cobalt and highlighter yellow accents, bold geometric typography, and high-speed triage buttons.

  • Vibe: Ultra-modern, energetic, crisp neo-brutalist utility.
  • Colors: Electric Cobalt (#2563eb), Laser Yellow (#fde047), Hot Magenta (#ec4899).
  • Key Features: High-contrast borders, solid offset drop-shadows, big interactive action triggers, instant exception filtering.

Concept C

Emerald Workshop & Clean Slate

Clean, highly structured atelier aesthetic using rich forest emerald, terracotta coral, crisp clean card surfaces, and accessible tabular progress bars.

  • Vibe: Professional craft studio, organized, balanced tactile precision.
  • Colors: Emerald Jade (#059669), Terracotta (#f97316), Deep Slate (#0f172a).
  • Key Features: Dual view mode (Card grid vs Table list), inline progress sliders, rich category chips, clean visual hierarchy.
